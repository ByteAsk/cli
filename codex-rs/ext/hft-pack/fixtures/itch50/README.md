# ITCH 5.0 fixtures

`synthetic-20261018.itch` is **invented data**: a seeded session generated by
`byteask_hft_pack::synthetic::session(20261018, 400)` (also `byteask-itch synthetic 20261018 400 OUT`).
It is not a capture of any real market and contains no licensed material. Two symbols (`AAA`, `BBB`),
start of day (System Event O, S, Q; Stock Directory), 400 book messages using every book type
(A, F, E, C, X, D, U, P) on a book that never crosses, end of day (M, E, C). Every message is preceded by
its 2-byte big-endian length, the layout of Nasdaq's binary capture files.

- `synthetic-20261018.messages.jsonl`: every message decoded (field names from the specification).
- `synthetic-20261018.events.jsonl`: the harness events (the port_check recording format).

The tests check that the generator still produces exactly these bytes (sha256 pinned in `src/tests.rs`),
that decoding gives exactly the golden files under the replay library, and that a one-byte change is
reported at the right message. Regenerate on purpose only: `BYTEASK_UPDATE_FIXTURES=1` on the
`the_checked_in_fixture_is_exactly_what_the_seeded_generator_produces` test, then update the pinned sha256.

Message layouts follow the public Nasdaq TotalView-ITCH 5.0 specification, sections 1.1-1.5.
