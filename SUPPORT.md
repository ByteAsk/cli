# Getting help

- **Questions and how-to:** start a [discussion](https://github.com/ByteAsk/cli/discussions) in the Q&A category.
- **Bugs:** open an [issue](https://github.com/ByteAsk/cli/issues/new/choose) with the bug report form.
- **Install or update problems:** open an issue with the install problem form, and include the installer output.
- **Account, plan or billing questions for the hosted service:** email support@byteask.ai. These are not handled
  in this repository.
- **Security problems:** do not open an issue; follow [SECURITY.md](SECURITY.md).

Before opening an issue, run `byteask doctor` and include its output, with keys and tokens removed.
